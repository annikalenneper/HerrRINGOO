# Hashtag-Sets

Vordefinierte Hashtag-Gruppen je Kategorie/Thema, um Recherchearbeit bei jedem Post zu sparen.
Sets können bei Bedarf gemischt werden (allgemeine Marken-Hashtags + kategoriespezifische).

## Marke (bei (fast) jedem Post)

```
#HerrRINGOO #RollendesTrauringstudio #Trauringe #Eheringe
```

## Werkstatt & Prozess

```
#Handwerk #Goldschmiede #MadeByHand #Ringschmieden
```

## Unterwegs / Standorte

```
#Popup #UnterwegsFuerEuch #TrauringeVorOrt
```

## Kundengeschichten

```
#RealCouples #JaWort #Verlobung #Hochzeitsplanung
```

## Ring im Detail

```
#Trauringe #Eheringe #TrauringeIndividuell #Ringpaar
```

## Team & Menschen dahinter

```
#TeamHerrRINGOO #Familienbetrieb #GenerationenHandwerk
```

## Community & Interaktion

```
#FragtUns #EureMeinung #HerrRINGOOCommunity
```

## Termine & Aktionen

```
#DatGibbet #TrauringTermin #PopUpTermin
```

## Trauring-Wissen

```
#TrauringTipps #RatgeberHochzeit #FaqTrauringe
```

## Lokal / Region

Aus den lokalen SEO-Keywords in Abschnitt 8 des
[Markenkommunikation-Guides](../markenkommunikation-guide.md) – v. a. für Posts mit
Standortbezug:

```
#TrauringstudioSauerland #TrauringeSiegerland #KreisOlpe #HochsauerlandKreis #SiegenWittgenstein #Kirchhundem
```

> Neue Sets hier ergänzen, bestehende Sets bei Bedarf verfeinern (z. B. nach Performance-Daten
> aus Instagram Insights).
