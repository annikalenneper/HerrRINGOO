# Captions

Dieser Ordner enthält **wiederverwendbare Textbausteine** für Instagram-Captions – nicht die
fertigen Captions einzelner Posts (die stehen direkt in der jeweiligen Datei in
[`../posts/`](../posts/README.md)). Ziel ist es, einen einheitlichen Ton und wiederkehrende
Elemente (Begrüßung, Call-to-Action, Hashtags) nicht jedes Mal neu erfinden zu müssen.

## Dateien

- [`bausteine-intros.md`](bausteine-intros.md) – Einstiegssätze/Hooks für verschiedene Post-Arten.
- [`bausteine-ctas.md`](bausteine-ctas.md) – Call-to-Action-Formulierungen (z. B. "Termin
  vereinbaren", "Kommentiert eure Meinung").
- [`hashtag-sets.md`](hashtag-sets.md) – Vordefinierte Hashtag-Gruppen je Kategorie/Thema.

## Verwendung

Beim Schreiben einer neuen Caption (in der jeweiligen Post-Datei) können Bausteine aus diesem
Ordner als Ausgangspunkt kopiert und individuell angepasst werden. Die Bausteine selbst sollten
möglichst **generisch** bleiben, damit sie für viele Posts wiederverwendbar sind.
