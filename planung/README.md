# Planung

Dieser Ordner enthält den **redaktionellen Plan** für Social Media – also die zeitliche Übersicht,
wann welcher Content (in welcher Kategorie, auf welcher Plattform) geplant, fertiggestellt und
veröffentlicht werden soll.

## Dateien

- [`content-kalender.md`](content-kalender.md) – tabellarische Übersicht aller geplanten und
  veröffentlichten Posts.

## Umgang mit dem Kalender

- Ein neuer Eintrag entsteht, sobald eine Idee aus der [`../ideensammlung/`](../ideensammlung/README.md)
  konkret genug für einen Zeitraum ist.
- Der **Status** wird laufend aktualisiert (siehe Legende in der Kalender-Datei).
- Der Eintrag verlinkt auf die zugehörige Datei in [`../posts/`](../posts/README.md), sobald diese
  angelegt wurde.
- Der Kalender ist bewusst **grob** (Woche/Monat statt exakte Uhrzeit) – die genaue
  Veröffentlichungsplanung erfolgt direkt in der jeweiligen Social-Media-App/-Tool.
