# Medien

Ablage bzw. Referenzpunkt für **Bild- und Videomaterial**, das in Posts (siehe
[`../posts/`](../posts/README.md)) verwendet wird.

## Struktur

- [`bilder/`](bilder/) – Fotos, Grafiken
- [`videos/`](videos/) – Videomaterial, Reels-Rohschnitt o. Ä.

## Hinweise

- Dateinamen so wählen, dass sie erkennen lassen, zu welchem Post/Thema sie gehören
  (`making-of-ehering-juli-01.jpg`), analog zur zugehörigen Post-Datei.
- Aus den Post-Dateien wird auf die Medien hier **verlinkt** (Feld `medien` im Frontmatter),
  nicht dupliziert.
- Große Video-Rohdateien müssen nicht zwingend über Git verwaltet werden – bei Bedarf reicht auch
  ein Verweis/Link auf den Ablageort (z. B. Cloud-Speicher), falls Dateigrößen das Repository
  unhandlich machen würden. Diese Entscheidung kann getroffen werden, sobald erste echte Medien
  hinzukommen.
